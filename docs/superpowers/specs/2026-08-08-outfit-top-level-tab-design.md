# 套装独立板块设计

## 目标

将“我的套装”从“任务”板块移出，成为首页顶部导航中的独立板块，顺序固定为“菜单 → 套装 → 计划 → 任务 → 关于”。保留套装的新建、查看、编辑、删除、一键加入拿衣清单和快速保存功能。

## 布局

- 顶部标签栏增加“套装”，标签区域允许横向滚动，搜索按钮仍固定在右侧。
- “套装”板块使用现有 `outfit-section` 组件，占据独立的纵向滚动内容区域。
- “任务”板块恢复为只展示拿衣清单摘要、任务输入和任务列表。
- 原有颜色、圆角、阴影和公主城堡视觉风格不变。

## 状态映射

- `activeTab === 0`：菜单
- `activeTab === 1`：套装
- `activeTab === 2`：计划
- `activeTab === 3`：任务
- `activeTab === 4`：关于

进入套装板块时按需加载套装；从套装编辑页返回且当前位于套装板块时静默刷新。其他数据流和云端接口不变。

## 交互与适配

- 标签保留足够的隐形触控高度，窄屏通过横向滚动访问全部标签，不压缩或截断文字。
- 搜索入口保持原功能和位置语义，不随标签区域滚动。
- 空状态、加载失败和缓存内容提示继续由现有套装组件处理。
- 套装详情面板与快速保存面板仍作为首页级浮层挂载，不受板块位置变化影响。

## 验证

- 更新标记测试，确认套装组件只出现在独立的 `activeTab === 1` 内容区域。
- 验证任务区域不再包含套装组件，计划、任务、关于的索引同步后仍可正常切换。
- 验证进入套装板块和从编辑页返回时的加载条件使用新索引。
- 运行全部 Node 测试、WXML 标签嵌套检查和 `git diff --check`。
