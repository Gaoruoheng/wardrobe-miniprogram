# 新增衣物保存按钮视觉设计

## 目标

把“甜蜜小窝”主题新增衣物页底部的“保存到衣柜”从无底色文字补全为粉红、可爱、清晰的主操作按钮，同时保留当前位置、固定底部、安全区、文案和 `saveItem` 保存逻辑。

## 方案比较

1. 草莓奶油胶囊（采用）：粉红渐变、白色文字、内侧高光、柔和粉棕阴影，既可爱又有明确主操作层级。
2. 珊瑚纯色按钮：对比清晰，但比现有“甜蜜小窝”视觉更硬，趣味性不足。
3. 粉红描边按钮：更轻盈，但在浅色页面底部容易显得像次要操作。

用户已授权无需逐项确认，直接设计并运行，因此采用方案 1。

## 视觉与交互

- 继续使用现有 `.save-btn`、固定定位和 100rpx 高度，不改变页面结构。
- 普通主题使用草莓粉到蜜桃粉的轻微渐变，白色高对比文字，圆形胶囊外观。
- 使用有垂直偏移和柔和模糊的阴影表达悬浮层级，并加入克制的内侧高光。
- 左右各放一个纯 CSS 奶油高光点作为装饰；不新增图片、Unicode 图标或包体积。
- 按下时轻微下移并收紧阴影，提供手机触控反馈。
- `prefers-reduced-motion` 下缩短过渡时间。
- 月宫主题现有紫色按钮样式保持不变。

## 验收标准

- 普通主题 `.save-btn` 明确定义粉红背景、白色文字、圆角、阴影和按压反馈。
- 按钮高度不低于全局 88rpx 触控目标，保留底部安全区。
- WXML 仍绑定 `saveItem`，文案仍为“保存到衣柜”。
- 不增加图片资源，不修改保存业务逻辑，不影响月宫主题覆盖。
