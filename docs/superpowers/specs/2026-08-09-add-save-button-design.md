# 新增衣物保存按钮视觉设计

## 目标

把“甜蜜小窝”主题新增衣物页底部的“保存到衣柜”补全为粉红、可爱、清晰的主操作按钮，并让配色与页面顶部标题卡保持一致，同时保留当前位置、固定底部、安全区、文案和 `saveItem` 保存逻辑。

## 方案比较

1. 顶部同款浅粉胶囊（采用）：直接复用标题卡的浅粉、深棕文字、描边和偏移阴影，主题一致性最高。
2. 浅粉渐变按钮：层次更丰富，但会继续产生一个页面中不存在的新色阶。
3. 白底粉边按钮：更轻盈，但在浅色页面底部容易显得像次要操作。

用户已授权无需逐项确认，直接设计并运行，因此采用方案 1。

## 视觉与交互

- 继续使用现有 `.save-btn`、固定定位和 100rpx 高度，不改变页面结构。
- 普通主题使用标题卡同款 `#FFE6EF` 浅粉背景、`#5C4B51` 深棕文字与描边，保持圆形胶囊外观。
- 使用与标题卡一致的深棕偏移阴影表达卡通层级，不引入新的深玫红色阶。
- 移除深玫红渐变和粉红装饰点；不新增图片、Unicode 图标或包体积。
- 按下时轻微下移并收紧阴影，提供手机触控反馈。
- `prefers-reduced-motion` 下缩短过渡时间。
- 月宫主题现有紫色按钮样式保持不变。

## 验收标准

- 普通主题 `.save-btn` 明确定义 `#FFE6EF` 背景、`#5C4B51` 文字与描边、圆角、阴影和按压反馈。
- 按钮高度不低于全局 88rpx 触控目标，保留底部安全区。
- WXML 仍绑定 `saveItem`，文案仍为“保存到衣柜”。
- 不增加图片资源，不修改保存业务逻辑，不影响月宫主题覆盖。
